# Command reference

Every action in folio is a named command. Commands can be bound to keys in `config.toml`,
run from the command palette (`:`), called from Lua with `folio.exec("name args")`,
or sent to a running instance with `folio --remote 'name args'`.

`:42` (a bare number) goes to page 42. Commands that need an argument prompt for it when run without one.
Lua commands defined with `folio.command` show up in the palette next to these.
